# Instant Mode

*Record and create a shareable recording with the shortest workflow*

Instant Mode is Vexy Screensese's fastest recording-to-link workflow. It uploads recording data while the session is active, then completes processing after you stop.

## Record in Instant Mode

1. Open Vexy Screensese and select **Instant**.
2. Choose a display, window, area, or camera-only target.
3. Select the camera, microphone, and supported audio options you want to include.
4. Click **Record** and complete the countdown.
5. Use the recording controls to pause, resume, restart, or stop.

If you prefer global controls, assign them first in **Settings > Shortcuts**. Vexy Screensese does not ship default recording hotkeys.

## After you stop

Vexy Screensese finalizes the upload and prepares the share page. Processing time depends on the recording and connection, so treat the link as ready only after Vexy Screensese reports it.

The recording appears in the desktop library and web dashboard, where you can copy its link, rename it, change supported access settings, organize it, or delete it.

## What viewers get

A public share link opens in a browser without requiring an account. Private and password-protected recordings enforce their configured access rules.

The viewer supports playback controls and the playback-speed options currently offered by Vexy Screensese. Captions, transcripts, summaries, chapters, downloads, comments, and reactions appear only when the content has been produced and the Vexy Screensese or organization settings allow them. Posting feedback requires sign-in.

## Storage

New Instant uploads use the active storage provider: Vexy Screensese-managed storage, an individual or organization Google Drive integration, or configured S3-compatible storage. Changing a provider affects future uploads; it does not automatically move existing recordings.

See Google Drive or the [S3 guides](../s3-config/aws-s3.md).

## When to use Instant Mode

Instant Mode fits bug reports, customer support, async updates, quick walkthroughs, and other cases where a shareable recording matters more than editing first.

Use [Studio Mode](studio-mode.md) when you want a local project, timeline editing, visual styling, or local export before sharing.
